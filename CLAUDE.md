#miAlmacen

es un proyecto para almacenes que puedan guardar el stock y al momento de vender se descuento del stock el producto, además que pueda generar códigos de barra personalizados y se puedan imprimir y pueda usar el mismo codigo de barra del producto, que el codigo de barra pueda ser escaneado con cualquier pistola laser para agregarlo al inventario y para venderlo

se debe ser compatible con 
- Windows
- Macs
- Linux

la base de datos debe estar dentro del proyecto 

stack a utilizar React - Electron - TypeScript
